# ComfyUI 工作流生成脚本规则

编写或修改生成 Web 界面工作流（UI 格式 JSON）的脚本时，必须遵守以下标准。
参考实现：`workflow_scripts/generate_workflows.py`。

## 语义化中文标题

- 每个节点必须有语义化中文标题，让用户一眼看出节点用途。
- 同类型节点（如多个 `LoadImage`）必须用标题区分各自用途，例如
  "证件照模板（发型/构图）"与"参考照片（身份来源）"。
- 标题写入节点 JSON 的 `title` 字段即可在画布上显示。
- 前端不支持自定义 tooltip 或 "?" 说明（悬停固定显示节点类型的官方英文描述），
  因此用途说明应融入标题（如"缩放画布 640×640"），不要依赖悬停提示传达信息。
- 在 API 格式转换时标题保留在 `_meta.title` 字段。

## 画布布局防重叠

- 画布布局必须保证任意高度节点不重叠：按依赖深度分列，列内 y 坐标累加
  （上一节点底部 + 间距），列间 x 坐标累加（上一列最大宽度 + 间距）。
- 不要使用固定行距——节点渲染后高度远超预设行距时必然重叠。

## 节点尺寸预留

- 节点 `size` 必须按渲染后的实际尺寸预留，不能只写逻辑尺寸。
- 图片类节点（`LoadImage`、`SaveImage`、`PreviewImage`）渲染后高度会大幅膨胀
  （官方模板中位数约 370-520px，甚至更高），只写逻辑尺寸会在画布上互相遮挡。
- 各节点类型渲染后尺寸可参考官方模板包
  `comfyui_workflow_templates_json/templates/*.json` 中同类型节点的统计中位数。

## 工作流功能说明（Note 节点）

- 每个生成的工作流必须附带一个 `Note` 节点说明其主要功能，放在画布
  左上角 `(LAYOUT_MARGIN, LAYOUT_MARGIN)`，主流程整体右移
  `NOTE_SIZE[0] + NODE_GAP_X` 为其留出空间，让用户打开工作流即可理解用途。
- Note 节点是前端内置类型（官方模板中大量使用）：`type: "Note"`、
  `inputs`/`outputs` 为空、说明文字放在 `widgets_values: [text]`，
  支持 `\n` 换行与 `**加粗**` 等 Markdown 语法。
- 说明内容应覆盖：工作流模式/用途、关键输入的角色（如哪张图是身份来源）、
  影响结果的核心参数（如 denoise、weight）及其含义、输出流程简述。
- Note 节点 id 使用最大节点 id + 1，不参与深度分列布局，也不与其他节点重叠。
- Note 无 class_type，转换为 API 格式时会被前端过滤，不影响执行与校验。

## 生成结果验证

生成完成后必须验证：
- 所有节点矩形两两不相交（x 区间与 y 区间均相交即重叠）。
- 每个节点都有语义化标题。
- 经 API 格式往返转换（`_meta.title` 保留）与工作流校验（`validate_workflow`）无错误。
